[Java Applet](https://en.wikipedia.org/wiki/Java_applet) to plot a series of GPS coordinates (lat, lon) in a world map.  Project authored circa 2005.
This applet was embedded in the [BuddyMap](https://github.com/LuisMSuarez/BuddyMap-ASP) website.
Note: the advent of more modern web technologies (HTML5 and beyond) lead to Java Applets being completely deprecated and retired, but in the 1990s and 2000s, they provided a means to embed a sandboxed subprogram in your website to provide a rich experience.
I still feel very proud of what I accomplished with this project.  Some highlights:

- Usage of Swing layout manager
- Usage of double-buffering graphics to provide smooth graphics
- Nifty zoom and fade transitions when the user switched maps
